## Critique (honnetete produit)

- [ ] **Chronologie fausse sur les trajets a correspondance.** Chaque jambe
  demarre au premier depart theorique de SA ligne, sans tenir compte de
  l'arrivee de la jambe precedente. Verifie sur /train/marrakech/tanger :
  Al Atlas 06:15 -> 08:55 a Casa, puis Al Boraq affiche depart Casa 06:00,
  arrivee Tanger 08:10 (avant meme d'etre arrive a Casa). Idem
  /train/marrakech/oujda. Fichier : lib/router.ts, buildTrip, curseur `first`.
  Correction : propager l'heure d'arrivee + 25 min et prendre le prochain
  depart de SCHEDULES superieur ou egal.
- [ ] **Comparaison carbone gonflee sur les detours ferroviaires.** carKg et
  planeKg utilisent les km du RAIL (Tanger -> Oujda = 955 km via Casa) alors
  que la voiture ferait ~600 km et l'avion ~500 km. L'avion ressort a 248 kg
  au lieu d'environ 130. Contraire a la regle "aucun chiffre gonfle".
  Fichier : lib/router.ts, carbonComparison. Correction : distance routiere
  ou orthodromique par paire (table ou formule haversine sur des coordonnees
  de gares), etiquetee "estimee".

## Haute (securite, dependances)

- [ ] **Next.js 15.5.20 : 8 avis de securite** (SSRF, cache confusion,
  DoS image optimization, disclosure endpoints). Tous corriges en 15.5.21.
  Plus nanoid <3.3.18. `npm audit fix` suffit, puis rebuild.
- [ ] **/api/concierge sans garde-fou** : aucune limite de debit, aucun
  controle d'origine, cle Mistral payante derriere. N'importe qui peut
  scripter des milliers d'appels. Correction minimale : verifier l'en-tete
  Origin/Referer contre NEXT_PUBLIC_SITE_URL et poser un rate limit
  (Vercel : middleware + Upstash, ou simple compteur memoire par IP
  en attendant).
- [ ] **Aucun ESLint configure** : `npm run lint` lance l'assistant
  interactif. Le script est mort. Soit installer eslint + eslint-config-next,
  soit retirer le script.
- [ ] **Pas de tests, pas de git.** CLAUDE.md annonce l'omni-saisie
  "testee 9/9" mais aucun test n'existe dans le depot. Le dossier n'est
  pas un depot git : aucun historique, aucun filet. Le script de
  verification du moteur utilise pour cet audit est reproductible en
  node --experimental-strip-types (voir section Verifs).

## Moyenne (SEO, i18n)

- [ ] `<html lang="fr">` sur TOUTES les pages, y compris /en/*
  (verifie dans .next/server/app/en.html). Penalise le SEO EN et
  l'accessibilite. Correction : lang dynamique dans app/layout.tsx via
  le groupe de routes, ou deplacer <html> dans chaque layout de locale.
- [ ] **hreflang en URLs relatives** (`href="/train/casa/fes"`). Google exige
  des URLs absolues. Ajouter `metadataBase: new URL(NEXT_PUBLIC_SITE_URL)`
  dans app/layout.tsx.
- [ ] **Pas de robots.ts, pas d'icon, pas d'opengraph-image, pas de
  not-found.tsx.** Le sitemap existe mais rien ne pointe dessus.
- [ ] **Liens affilies en locale FR sur les pages EN** : getyourguide.fr et
  booking.com/searchresults.fr.html. Passer un parametre locale a
  experiencesUrl/staysUrl (getyourguide.com, searchresults.en-gb.html).
- [ ] **Mentions legales illisibles** : credit photo en 8px, mention
  "lien partenaire" en 9px. Une divulgation d'affiliation doit etre lisible.
  Passer a 11px minimum.
- [ ] Documentation desynchronisee : CLAUDE.md annonce "~560 pages",
  "136 pages", "140 pages" ; le build en genere 277.
